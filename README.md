# Arus Publik

Dashboard eksplorasi APBD nasional dan navigasi wilayah menggunakan sumber resmi SIKD Kementerian Keuangan.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Catatan: ringkasan angka nasional pada versi pemulihan ini masih berupa data statis dan perlu diverifikasi terhadap sumber resmi sebelum diperlakukan sebagai data aktual.
